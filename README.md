## Proje Hakkında
ASP.NET Core MVC (.NET 10) ile geliştirilen; çoklu klinik, veteriner hekim,
evcil hayvan, aşı takibi ve randevu yönetimi sunan bir web uygulamasıdır.
REST API ve yapay zekâ asistanlarının kullanabileceği bir MCP sunucusu içerir.

**Teknolojiler:** ASP.NET Core MVC, EF Core (Code First, SQLite), Identity,
REST API, ModelContextProtocol.AspNetCore, Bootstrap 5, jQuery
